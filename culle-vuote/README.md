# Culle vuote, carrelli nuovi

Sito interattivo statico: natalità, famiglie, consumi e tecnologia, letti per la Distribuzione Moderna.

- `index.html`: la pagina, con grafici in d3 (caricato da cdnjs).
- `data.js` e `data/`: i dati usati, in CSV e in JSON.
- `report.pdf`: il report impaginato.

Pubblicato con GitHub Pages nella cartella culle-vuote del repository. È una bozza di lavoro: verificare le cifre riprese da stampa prima di diffonderla.
